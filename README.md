# Michael's Crossing apps: Windows downloads

Installers for the Windows editions of apps by **Michael's Crossing International, LLC**
(<https://www.michaelscrossing.com>). Each app asks for its **license key** on first start; buy one at
<https://www.michaelscrossing.com/buy>. Android editions are sold on Google Play.

Get the newest installers under **[Releases](../../releases/latest)**:

| App | File |
|---|---|
| OtoReader | `OtoReader-Setup.exe` |
| OtoScheduler | `OtoScheduler-Setup.exe` |
| BusinessLedger Pro | `BusinessLedgerPro-Setup.exe` |
| Storykeep | `Storykeep-Setup.exe` |
| OtoBookConverter | `OtoBookConverter-Setup.msi` |

## Installing

1. Download the file for your app and open it.
2. Windows may show **"Windows protected your PC"** because the installer is not yet signed with a publisher
   certificate. Click **More info**, then **Run anyway**.
3. Open the app, choose **Enter license key**, paste the key from your purchase page and press **Unlock**.

Help: support@michaelscrossing.com

## Open-source parts

OtoBookConverter includes **calibre** (GPL-3.0) as its conversion engine. calibre's complete source code for the
exact version included is attached to each release (`calibre-<version>.tar.xz`), as the GPL requires. The other
open-source components and their licences are listed inside each app.
